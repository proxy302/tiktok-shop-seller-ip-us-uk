## 1. 先看 TikTok 自己的规矩

买任何东西之前，先读 TikTok 官方的页面：

- [Requirements to register as a seller on TikTok Shop](https://ads.tiktok.com/help/article/requirements-to-register-as-a-seller-on-tiktok-shop)：其中写明，你必须居住在为店铺选择的国家；注册用的手机号或邮箱不能已经属于另一家 TikTok Shop。
- 美国站、英国站各自的卖家注册页，会列出该市场要的企业资料、身份核验和收款账户要求。这些会变，以你申请当天看到的为准。

顺序不能反：先符合开美国店或英国店的条件，再在同一个国家选 IP。IP 不是取得某个市场资格的办法，也代替不了任何验证。TikTok 要求验证时，用你自己的真实资料如实完成。

## 2. 固定 IP 对一家店有什么用

用家里或办公室的普通网络也能开店。下面几种情况，配一条固定 IP 才值得：

- **家用宽带的公网地址过几天就变一次**，卖家中心一次次看到新的网络。
- **在联合办公空间、共享办公室干活**，出口地址很多不相干的人都在用。
- **同一个国家里有几个人打理这家店**，分别在办公室、家里、出差的笔记本上。都通过同一个配置、同一条 IP，店铺就只有一个地址。
- **你经营不止一家企业，每家有自己的店。** 每家店单独一条 IP、一个配置，连接互不混用。

它的作用是让合规店铺的连接保持一致。它解除不了限制，解决不了违规问题，也不会让多开的店变得被允许。

## 4. 一家店的配置步骤

1. **买一条静态 ISP IP**，国家选店铺所在国（美国或英国）。
2. **先在终端里看出口**（USER、PASS、HOST、PORT 是占位符）：

   ```bash
   curl -sS -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
   ```

   `country` 应是你买的 `US` 或 `GB`，`org` 应是网络运营商，不是托管公司。
3. **给这家店建一个浏览器配置**：可以是装了代理扩展的独立 Chrome 用户配置，也可以是指纹浏览器里新建的配置。填好主机、端口、用户名、密码，在配置里打开 `https://ipinfo.io/json` 对一下。
4. **卖家中心只从这个配置打开。** 书签只放在这里，别处不放。
5. **把 IP 留住。** 打开自动续费，或记下到期日。续费还是同一条 IP；过期的 IP 会被收回，再下单就是另一个地址。

店主自己的手机上、人在店铺所在国时用 TikTok App，属于正常使用，不需要挂代理。要避免的是几家店挤在同一部手机、同一个配置或同一条 IP 上。

## 5. 团队协作，不共用密码

TikTok 的帮助页 [Roles and permissions in Seller Center](https://ads.tiktok.com/help/article/roles-and-permissions-in-seller-center) 列了八种角色，包括客服（Customer Service Agent）、订单履约（Order Fulfillment Specialist）、商品管理（Product Management Specialist）、财务（Finance Specialist）和广告（Advertising Manager），并写明用户管理只有店主账号看得到。所以：

- 店主按每个人的工作给对应角色。
- 大家都在这家店的配置里工作，用自己的身份登录。
- 主账号、它绑定的手机号和邮箱留在店主手上。
- 有人离职，店主删掉他的用户，IP 不用动。

## 6. 常见错误和办法

| 现象 | 原因 | 办法 |
|---|---|---|
| 反复弹出新登录提示 | 有人在配置以外打开卖家中心 | 一个配置，一个入口 |
| 一个月后配置连不上 | IP 租期到了 | 提前续费，或打开自动续费 |
| 407 Proxy Authentication Required | 用户名或密码填错 | 从控制台重新复制 |
| Chrome 扩展连 SOCKS5 IP 失败 | Chromium 不能用账号密码登录 SOCKS5 | 买 HTTP 协议的 IP |
| `ipinfo` 显示托管公司 | 用的是机房 IP | 换成静态 ISP IP |
| 两家店共用一个地址 | 复制配置时连代理一起复制了 | 一家店一条 IP，逐个配置检查 |

## 7. 常见问题

**我有一家美国店、一家英国店，用一条 IP 还是两条？**
两条，各在自己的国家、各用一个配置；前提是 TikTok 按它的规矩同时接受了你在这两个市场开店。

**IP 要和我在同一个城市吗？**
关键是国家。订购页能选城市的话，选离你近的，选定后别换。

**TikTok Shop 和亚马逊账户能用同一条 IP 吗？**
两个都属于同一家企业、由同一拨人打理，就可以。不少卖家还是一个平台一个配置，出了问题更容易看出来。

**店铺被要求验证，换一条更好的 IP 有用吗？**
没用。提交真实资料。没有哪条 IP 能代替验证。

**有免费试用吗？**
没有。想用真实的一天把流程走一遍，就租一条静态 ISP IP 24 小时，0.50 美元。
